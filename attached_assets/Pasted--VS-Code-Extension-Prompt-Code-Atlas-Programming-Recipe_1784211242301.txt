# VS Code Extension Prompt – Code Atlas (Programming Recipe Book)

## Objective

Build a production-quality Visual Studio Code extension called **Code Atlas**.

The goal is to create a **Minecraft Recipe Book / Creative Inventory for programming languages**.

Instead of requiring developers to know what to search for, they should be able to visually browse every built-in language feature, standard library API, and framework API from a sidebar, inspect it, understand it, and insert working code into their editor.

This should feel like exploring an encyclopedia rather than reading documentation.

---

# Core Philosophy

Programming currently works like this:

> "I need to know the name before I can search."

Code Atlas should work like this:

> "I know I need to work with arrays. Show me everything arrays can do."

Everything should be discoverable.
